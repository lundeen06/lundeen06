# Hello, I'm Lundeen! 👋

I'm a student at Stanford studying computer science and doing aerospace things. I have tons of interests, but recently I've found the most joy working on GNC, AI, satellites, and embedded projects.

**What I'm working on:**

* 🛰️ [SAMWISE GNC flight code](https://github.com/stanford-ssi/samwise-adcs-flight) — Attitude Determination & Control System (ADCS) software built from the ground up for SAMWISE, Stanford SSI's 2U CubeSat. We're building a low-cost bus (<$10k/unit!) with cameras, reaction wheels, a star tracker, S-band comms, and lots more. Launching in October 2026!

**A few projects I love:**

* ☀️ [smarter sun sensors](https://github.com/lundeen06/smarter-sun-sensors) — Recovering a nadir vector from coarse sun sensors by modeling reflected Earth light. It's a wonderfully strange inference problem, and a path toward cheaper, more fault-tolerant satellites.
* 🌲 [TreeSats / Starguard](https://github.com/lundeen06/treesats) — Onboard debris detection, collision avoidance, and adversarial threat assessment for satellites operating without GPS or ground contact.
* 🌠 [NODE](https://github.com/lundeen06/node) — An AI-enabled satellite constellation operations platform built at the [2026 National Security Hackathon](https://cerebralvalley.ai/e/3rd-annual-natsec-hackathon), with orbital visualization, conjunction screening, and operator-gated maneuver planning.

**Tools that escaped the lab:**

* 🧭 [MAGCAL](https://github.com/lundeen06/magnetometer-calibration-tool) — A packaged Python CLI for ellipsoid-fit magnetometer calibration that exports parameters straight to embedded C.
* 🧲 [magnetorquer designer](https://github.com/lundeen06/magnetorquer-designer) — Physics, thermal, and manufacturing optimization for PCB magnetorquers, plus automated KiCad trace generation. Built for SAMWISE!
* 🌀 [SAMWISE GNC simulations](https://github.com/stanford-ssi/samwise-adcs-sims) — A 6-DOF attitude propagator for validating our flight algorithms.
* 📆 [WhenNot2Meet](https://when2notmeet.com) — Mark when you can't meet. Meet. Repeat.

I like ambitious systems, cheap hardware doing surprisingly smart things, and projects where software eventually has to face physics. If you're working on something in that neighborhood, I'd love to hear about it :)
